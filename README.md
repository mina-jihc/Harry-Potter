## About the Project

Harry Potter is a frontend web application that allows users to explore characters from the Harry Potter universe.

The application retrieves character data from an external API and dynamically displays character cards with information such as name, alternate name, date of birth, ancestry, and Patronus.

Users can search for characters by name and filter them by Hogwarts house.

## Features

- Browse Harry Potter characters
- Search characters by name
- Filter characters by Hogwarts house
- Display character information dynamically
- View character images
- Add characters to favourites
- Interactive navigation
- Responsive character card layout

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- REST API
- JSON
- DOM manipulation

## API

This project uses the Harry Potter API:

https://hp-api.onrender.com/api/characters

The application sends a request to the API and uses the returned JSON data to generate character cards dynamically.

## How It Works

1. The application sends a request to the Harry Potter API.
2. The API returns character data in JSON format.
3. JavaScript processes the received data.
4. Character cards are created dynamically and displayed on the page.
5. Users can search characters by name.
6. Users can filter characters by Hogwarts house.
7. Users can mark characters as favourites.
